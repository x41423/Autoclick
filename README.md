# MouseClick Helper

> 浏览器自动化点击助手 · 可视化脚本录制 · 小键盘快捷启动

MouseClick Helper 是一款基于 Chrome 扩展的自动化工具，支持通过可视化点选录制鼠标点击操作，生成可回放的自动化脚本。内置独立的 Offscreen 执行引擎，即使页面刷新也能自动恢复执行。右侧小键盘区域可绑定最多 44 个独立快捷键，实现秒级启动任意脚本。

---

## ✨ 特性

- **🎯 可视化坐标拾取**：悬停高亮元素，点击锁定，方向键微调，一键生成点击坐标。
- **🔄 连续拾取模式**：一次拾取多个元素，按 `Enter` 确认后继续，效率倍增。
- **⏱️ 延迟控制**：支持自定义毫秒级延迟，精准控制操作节奏。
- **📦 离线执行引擎**：基于 Offscreen Document 运行，独立于页面生命周期，刷新、跳转不中断。
- **🔄 页面刷新自动恢复**：执行中刷新页面，脚本自动继续运行（无需用户干预）。
- **⌨️ 小键盘快捷键**：绑定 44 个独立快捷键（数字 0-9、加减乘除，组合 Ctrl/Alt/Shift），主键盘不受影响。
- **📁 脚本管理**：创建、编辑、删除、重命名、设置默认脚本，支持拖拽排序动作。
- **📤 导入/导出**：一键备份所有脚本，或迁移至其他设备（自动处理重名冲突）。
- **📋 完整日志系统**：所有操作记录持久化，便于调试和问题追踪。
- **🖥️ 悬浮进度条**：脚本执行时显示当前步骤、总数、剩余时间，支持暂停/继续。

## 🚀 安装

### 从源码加载（开发模式）
1. 下载本项目源码，解压到本地文件夹。
2. 打开 Chrome，访问 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择项目根目录。
5. 插件图标将出现在浏览器工具栏中。

> 注意：本插件使用 Manifest V3，需要 Chrome 88 及以上版本。

## 🕹️ 快速上手

### 1. 创建脚本
- 点击插件图标，在弹窗中点击 **“➕ 新建脚本”**。
- 输入脚本名称（如“登录流程”），点击确定。

### 2. 添加动作
- 点击脚本右侧的 **“✏️ 编辑”** 进入编辑模式。
- **添加延迟**：输入毫秒数，点击 **“⏱️ 添加延迟(ms)”**。
- **添加点击**：
  - 点击 **“🎯 添加点击”**。
  - 页面会进入拾取模式，移动鼠标悬停到目标元素（出现高亮边框）。
  - 点击锁定，可用方向键微调坐标。
  - 按 `Enter` 确认（若开启连续模式，继续拾取下一个；否则退出）。

### 3. 调整动作顺序
- 在编辑器中，通过拖拽或点击 **↑/↓** 按钮调整动作顺序。
- 点击 **✕** 删除多余动作。

### 4. 保存并运行
- 点击 **“💾 保存”** 退出编辑。
- 在脚本列表点击 **“▶ 运行”**，脚本立即在当前页面执行。

## ⌨️ 快捷键系统

### 全局快捷键（Chrome 命令）
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+B` | 运行默认脚本 |
| `Ctrl+Shift+X` | 停止当前脚本 |

### 小键盘独立快捷键（44 个可绑定）
| 类型 | 键位 | 数量 |
|------|------|------|
| 裸按 | `0-9`, `+`, `-`, `*`, `/` | 14 |
| `Ctrl+` | `0-9` | 10 |
| `Alt+` | `0-9` | 10 |
| `Ctrl+Shift+` | `0-9` | 10 |
| **合计** | | **44** |

**绑定方法**：
- 在弹窗脚本列表中，点击脚本右侧的 **“🔢 绑定”**。
- 按提示在小键盘区域按下想绑定的组合键（如 `Alt+1`）。
- 若已绑定，可点击 **✕** 清除。

**触发方式**：
- 在任意网页上，直接按下已绑定的组合键，脚本立即运行。
- 主键盘数字区不受影响，可在输入框中正常输入。

## 🧩 高级功能

### 连续拾取模式
- 编辑脚本时，勾选 **“🔁 连续拾取”**。
- 点击“添加点击”进入拾取，每按一次 `Enter` 保存当前坐标，拾取器不退出，继续拾取下一个。
- 按 `ESC` 退出拾取模式，所有拾取点一次性添加到动作列表。

### 暂停/继续执行
- 脚本运行时，悬浮进度条右下角显示 **“⏸ 暂停”** 按钮，点击可临时暂停执行。
- 按 `Ctrl+Shift+X` 可强制停止。

### 脚本导入/导出
- **导出**：点击 **“📤 导出”**，所有脚本打包为 `.mcsx` 文件。
- **导入**：点击 **“📥 导入”**，选择之前导出的文件，自动合并脚本（重名时自动重命名并添加 `(导入)` 后缀）。

### 日志查看
- 点击 **“📋 日志”** 打开日志面板，显示所有操作记录。
- 点击 **“🗑️ 清空”** 可清除日志。

 ❓ 常见问题
Q：拾取器无法锁定某些元素（如下拉菜单、模态框）？
A：在拾取器激活状态下，按 空格键 暂停，此时页面交互恢复正常，可展开下拉或模态框，再按空格继续拾取。

Q：脚本在执行时页面刷新了，会怎样？
A：插件内置了 Offscreen 引擎，刷新后约 1 秒会自动恢复执行，浮窗重新出现，进度保持不变。

Q：小键盘快捷键在输入框中无效？
A：这是故意设计，避免干扰正常输入。在输入框（input/textarea）中，所有小键盘快捷键被自动屏蔽，可正常输入数字。

Q：如何临时禁用所有小键盘快捷键？
A：激活拾取器时，快捷键会自动禁用；退出拾取器后恢复。也可手动在 shortcut.js 中调用 setEnabled(false)。

Q：脚本可以跨标签页执行吗？
A：脚本始终运行在当前活动标签页。如需在多个标签页执行，请在每个标签页单独启动。

Q：能否录制右键点击或滚轮操作？
A：当前版本仅支持左键点击和延迟，未来可能扩展更多动作类型。
